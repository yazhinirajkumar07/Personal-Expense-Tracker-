# Spendly — Advanced Personal Expense Tracker

A polished ReactJS personal finance dashboard built for a college web-development assignment.

## Features
- Dashboard with balance, income, expense and budget cards
- Add / edit / delete transactions
- Client-side form validation
- Search and filter
- Income vs expense charts
- Category spending analytics
- Monthly budget planner
- CSV export
- LocalStorage persistence
- Responsive mobile/tablet/desktop UI
- Dark / light theme
- React Router pages
- React components, JSX, useState and useEffect
- HTML5 + CSS3 + ES6

## Pages
- `/` — Overview
- `/transactions` — Transaction manager
- `/analytics` — Analytics
- `/budget` — Budget Planner
- `/settings` — Settings

## Run
```bash
npm install
npm run dev
```

Then open the URL shown by Vite, normally `http://localhost:5173`.

## Project structure
```text
src/
  App.jsx
  main.jsx
  styles.css
```

The app intentionally keeps the code easy to understand and modify for an academic submission while providing a premium interface.
